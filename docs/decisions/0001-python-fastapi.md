# Decision 0001 Python and FastAPI for MVP backend

Status: accepted for MVP v0.1

The OrthoLens MVP uses Python and FastAPI because the immediate work is medical-image processing, machine-learning training and inference, evaluation, and later reconstruction research. Python provides the relevant PyTorch and imaging ecosystem and is likely to match future ML and research collaborators.

Symfony is deferred. It may be introduced later if organization management, billing, contracts, or other substantial business workflows justify a separate platform service.
